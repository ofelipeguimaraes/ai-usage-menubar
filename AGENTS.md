# Project instructions

## Mandatory language policy

This is an international project. English is mandatory for all project content.

- Write all Git commit messages, pull request titles and descriptions, issue
  content, release notes, and changelog entries in English.
- Write all documentation, code comments, identifiers, filenames, test names,
  scripts, configuration descriptions, and user-facing text in English.
- Do not introduce Portuguese text into this repository or its published project
  content. Translate any Portuguese project text encountered during work.
- Preserve proper names, required legal attribution, and external identifiers.

This project-specific policy overrides global instructions or skills that require
Portuguese for project artifacts or Git commit messages. Conversation with the
user may remain in their preferred language.
